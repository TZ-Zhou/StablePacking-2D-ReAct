# docs：專案文件

StablePacking-2D-ReAct 的計畫、規格、決策、觀念與查證文件，一律放這裡。各資料夾的 README、agent 工作規則（`.claude/`）與研究結論（`research/findings.md`）不放這裡。

## 內容

| 項目 | 放什麼 |
| --- | --- |
| `plans` | 計畫：要做什麼、怎麼做、實作順序、待決事項；例如 `runs-archive-and-cases.md` |
| `specs` | 規格與契約：檔案格式、id 規則、欄位定義，也就是實作完成後仍然成立的規則 |
| `decisions` | 長期決策：選了什麼、依據、何時重新檢討 |
| `concepts` | 觀念筆記：一個主題一個檔，不寫專案現況 |
| `reviews` | 查證、文獻與討論素材，不在執行範圍 |
| `TODO.md` | 尚未完成的項目 |
| `HANDOFF.md` | 換電腦接手的步驟與目前狀態 |

## 存放規則

- 一件事只住一個位置：依資訊種類放進上表的資料夾，不依日期或路線分；別處要用就連結過來，不重寫。
- 檔名用英文小寫加連字號，一個主題一個檔。
- 只寫現在成立的事，規則見 `.claude/DOC_STYLE.md`。計畫做完後，仍成立的規格搬進 `specs`，計畫檔刪除，沿革留給 git。
- 某個資料夾超過 6 個檔時，在該資料夾加 README 列出各檔。
