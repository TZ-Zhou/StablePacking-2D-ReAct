# Tests：論文各範例案例的執行腳本與輸入資料

## 內容
| 項目 | 說明 |
| --- | --- |
| `Almeida/` | 規則、半規則、不規則三類石材的砌牆案例，可用 `run_all.py` 一次執行；見該處 readme |
| `Bricks/` | 以單位磚影像堆疊磚牆，`run.py` 內切換兩種長高比，輸入影像在 `data/` |
| `FFT_stones/` | 以傅立葉描述子生成石材集並砌牆、評估與繪圖；見該處 readme |
| `Rubble_stone_walls/` | 以真實亂石牆照片分割出的石材砌牆、重建與量測；見該處 readme |
| `Thangavelu/` | 以文獻標註的石材影像砌牆，含多組擬合度與穩定度評估；見該處 readme |

## 使用
進入案例資料夾執行檔名含 `run` 的建牆腳本（各案例 readme 有說明，`FFT_stones/` 要先生成石材）；其後編號腳本負責檢視、評估、繪圖與動畫。
結果寫到該案例資料夾內以 `result` 開頭的子資料夾（`Almeida/` 為各子案例下的 `result/`，其餘帶時間戳記）。
